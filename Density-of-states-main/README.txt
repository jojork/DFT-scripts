For dos_loop script you must have gpw files of each nanoribbon.
Suppose yu have nanoribbon of 5 unit cell so you should have gpw file of nanoribbon of 1 unit cell, nanoribbon of 2 unit cell and so on.
Then you have to put the gpw file name as input in the script and keep the * as it is.
Then script will automatically calculates the dos of each step and at last give the collective dos plot.
